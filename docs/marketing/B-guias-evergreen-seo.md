# B — Plan de 10 Guías Evergreen SEO

> Contenido educativo que rankea en Google **sin necesidad de que la app funcione todavía**.
> Cada guía termina con CTA a la lista de espera.

---

## 🎯 Objetivo

Plantar semillas SEO **hoy** para que cuando lances en X meses, ya tengas tráfico orgánico llegando.

**Métrica única a mover:** páginas indexadas + posición en Google.

---

## 🌱 Por qué esto importa pre-launch

```
   Mes 0 (HOY)        Mes 3            Mes 6            Mes 12
   ──────────         ─────            ─────            ──────
   Publicás 10        Google empieza   Rankean en      Tráfico
   guías              a indexar        long-tail       compounding
   ───┬───            ───┬───          ───┬───         ───┬───
      │                  │                │               │
      ▼                  ▼                ▼               ▼

                                                       de visitas/día
                                                       gratis al launch
```

**Si esperás al launch para empezar SEO, perdiste 6-12 meses.**

## 📋 Las 10 guías (priorizadas por volumen y intención)

### 🔥 TIER 1 — Alta intención comercial (publicar primeras)

#### 1. Cómo reclamar a Mercado Libre paso a paso (Argentina)

```
┌────────────────────────────────────────────────────┐
│  Búsquedas mensuales:    ~8.000-15.000 (alta)     │
│  Dificultad SEO:         Media                     │
│  Intención:              Comercial alta            │
│  URL:                    /guias/                   │
│                          como-reclamar-mercado-    │
│                          libre-argentina           │
└────────────────────────────────────────────────────┘
```

**Estructura:**
- Cuándo conviene reclamar a ML (no entregado, falsificado, vendedor fantasma)
- Reclamo dentro de la plataforma (paso a paso con screenshots)
- Si ML no responde: carta documento (modelo descargable)
- Defensa del Consumidor (cuándo escalar)
- Casos comunes resueltos (3-5 ejemplos genéricos)
- FAQ: 10 preguntas frecuentes

**Por qué primero:** ML es la búsqueda #1 en AR. Volumen + tu base de datos ya tiene stats de ML.

```
│                          como-reclamar-telcel-     │

└────────────────────────────────────────────────────┘
```

**Estructura:**
- Quejas más frecuentes (cobros indebidos, internet caído, portabilidad bloqueada)

**Tip:** Hacé una variante por cada operador (Telcel, AT&T, Movistar) = 3 guías con 80% del contenido reutilizado.

## 🗓️ Cronograma de publicación

```
SEMANA 1:  Guía #1 (Mercado Libre AR) + #3 (Carta documento AR)
           ┌─ Empezás con AR porque tenés más datos / contexto

SEMANA 2:  Guía #2 (Telcel MX) + #4 (PROFECO MX)
           ┌─ Mismo patrón en MX

SEMANA 3:  Guía #6 (Cargos tarjeta) + #8 (Suscripciones)
           ┌─ Quejas masivas, búsqueda alta

SEMANA 4:  Guía #5 (Vuelo) + #7 (Garantía)
           ┌─ Long-tail con buena intención

SEMANA 5:  Guía #9 (Defensa Consumidor) + #10 (Compra online)
           ┌─ Cierran el set

DESPUÉS:   Variantes (Movistar, AT&T, Spotify, Netflix, etc.)
           Cada una = 80% reciclable de las anteriores
```

**Cadencia post-set:** 1 guía nueva por semana. En 6 meses tenés ~30 guías rankeando.

## 🏗️ SEO técnico (sin código por ahora — checklist conceptual)

Cada guía necesita:

```
✓ Title tag optimizado (60 chars máx)
✓ Meta description (155 chars máx)
✓ H1 único = pregunta exacta del usuario
✓ Headings jerárquicos (H2 secciones, H3 subsecciones)
✓ Schema HowTo + FAQPage (te da rich snippets en Google)
✓ Imagen destacada con alt text
✓ Tabla de contenidos clickeable (mejora dwell time)
✓ Internal linking entre guías relacionadas
✓ Última actualización visible (Google premia frescura)
✓ Tiempo de lectura estimado
✓ Author box (Dante + bio breve = E-E-A-T)
```

**Schema markup:** ya tenés esto en el roadmap, podés correr el skill `schema-markup` después.

## 🛠️ Herramientas recomendadas

```
INVESTIGACIÓN:
├─ Google Keyword Planner (gratis)        ← volumen real de búsqueda
├─ AnswerThePublic (gratis tier)          ← preguntas relacionadas
├─ Google Search Console (gratis)         ← qué ya estás rankeando
└─ Ahrefs / SEMrush (pago)                ← solo si presupuesto

REDACCIÓN:
├─ Tu propio editor + un LLM              ← Claude para drafts, vos editás
└─ Hemingway Editor (gratis)              ← legibilidad

PUBLICACIÓN:
├─ Markdown en /content/guias/            ← Next.js puede renderlo
└─ MDX si querés componentes embebidos    ← para CTAs, calculadoras inline
```

## ✅ Checklist por guía antes de publicar

```
[ ] H1 es exactamente lo que el usuario googlea
[ ] TL;DR en los primeros 100 palabras
[ ] Tabla de contenidos
[ ] Mínimo 1 imagen / diagrama / screenshot
[ ] Modelo descargable con email opt-in
[ ] CTA a lista de espera al final
[ ] Schema HowTo o FAQPage agregado
[ ] Internal links a 2-3 guías relacionadas
[ ] Meta description con keyword + diferencial
[ ] Tested en Google Rich Results Test
[ ] URL limpia, sin parámetros raros
[ ] Submit a Google Search Console
```

## ⚠️ Errores típicos a evitar

| Error | Por qué duele |
|-------|---------------|
| Copiar artículos de blogs legales existentes | Google detecta y penaliza |
| Hacer la guía un anuncio de JustIA | Si no entrega valor educativo, rebote alto |
| No incluir el modelo descargable | Pierdes el 80% de las captures |
| Publicar 10 guías en 1 día | Google sospecha de spam masivo |
| Usar IA para todo el texto sin editar | Lectores notan y rebotan |
| No actualizar nunca | Google premia frescura |
