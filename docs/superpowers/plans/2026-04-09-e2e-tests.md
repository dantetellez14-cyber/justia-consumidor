# E2E Tests (Playwright + MSW) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Instalar Playwright + MSW, escribir 8 tests E2E que cubren el flujo consumidor y el flujo auth, y configurar GitHub Actions para que corran en cada PR.

**Architecture:** MSW intercepta las llamadas a `/api/analyze`, `/api/cases`, `/api/send-complaint` y `/api/feedback` en el browser antes de que lleguen al servidor real. `@clerk/testing/playwright` inyecta un usuario de prueba sin password real. Los tests corren contra `next start` (build de producción) tanto local como en CI.

**Tech Stack:** `@playwright/test`, `msw@2`, `@clerk/testing`, Next.js 16, GitHub Actions

- [ ] **Step 1: Crear src/lib/msw-init.ts**

```typescript
export async function initMSW() {
  if (typeof window === "undefined") return;
  if (process.env.NEXT_PUBLIC_MSW_ENABLED !== "true") return;

  const { worker } = await import("../../e2e/mocks/worker");
  await worker.start({
    onUnhandledRequest: "bypass",
    serviceWorker: {
      url: "/mockServiceWorker.js",
    },
  });
}
```

const RELATO_INPUT = 'textarea[placeholder*="Describí"]';
const SUBMIT_BTN = 'button[type="submit"]';

test.describe("Consumer flow", () => {
  test("formulario → analisis IA muestra empresa y probabilidad", async ({
    page,
  }) => {
    await page.goto("/");

    // Pasar la pantalla de bienvenida
    await page.getByRole("button", { name: /comenzar|empezar|iniciar/i }).click();

      "Telecom me cobró 3 meses de internet que no funcionó. Quiero que me devuelvan $15000."

    // Esperar resultado del análisis (MSW responde con mockAnalysis)
    await expect(
      page.getByText(mockAnalysis.empresa)
    ).toBeVisible({ timeout: 15_000 });

    await expect(
      page.getByText(/75%|0\.75|probabilidad/i)
    ).toBeVisible();
  });

  test("analisis → genera carta de reclamo", async ({ page }) => {
    await page.goto("/");
    await page.getByRole("button", { name: /comenzar|empezar|iniciar/i }).click();

    await page.locator(RELATO_INPUT).fill(
      "Telecom me cobró 3 meses de internet que no funcionó. Quiero que me devuelvan $15000."

      page.getByText(/carta|reclamo formal|estimado/i)

  test("usuario autenticado envia reclamo a empresa", async ({ page }) => {

    await expect(page.getByText(mockAnalysis.empresa)).toBeVisible({
      timeout: 15_000,

    await page.getByRole("button", { name: /comenzar|empezar|iniciar/i }).click();

    await page.locator(RELATO_INPUT).fill(
      "Telecom me cobró 3 meses de internet que no funcionó. Quiero que me devuelvan $15000."

## Task 8: GitHub Actions workflow

**Files:**
- Create: `.github/workflows/e2e.yml`

- [ ] **Step 1: Crear .github/workflows/e2e.yml**

```yaml
name: E2E Tests

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  e2e:
    runs-on: ubuntu-latest
    timeout-minutes: 20

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm

      - name: Install dependencies
        run: npm ci

      - name: Install Playwright browsers
        run: npx playwright install --with-deps chromium

      - name: Build app
        run: npm run build
        env:
          NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY: ${{ secrets.NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY }}
          CLERK_SECRET_KEY: ${{ secrets.CLERK_SECRET_KEY }}
          NEXT_PUBLIC_SUPABASE_URL: ${{ secrets.NEXT_PUBLIC_SUPABASE_URL }}
          NEXT_PUBLIC_SUPABASE_ANON_KEY: ${{ secrets.NEXT_PUBLIC_SUPABASE_ANON_KEY }}
          SUPABASE_SECRET_KEY: ${{ secrets.SUPABASE_SECRET_KEY }}
          NEXT_PUBLIC_MSW_ENABLED: "true"

      - name: Run E2E tests
        run: npm run test:e2e
        env:
          NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY: ${{ secrets.NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY }}
          CLERK_SECRET_KEY: ${{ secrets.CLERK_SECRET_KEY }}
          NEXT_PUBLIC_SUPABASE_URL: ${{ secrets.NEXT_PUBLIC_SUPABASE_URL }}
          NEXT_PUBLIC_SUPABASE_ANON_KEY: ${{ secrets.NEXT_PUBLIC_SUPABASE_ANON_KEY }}
          SUPABASE_SECRET_KEY: ${{ secrets.SUPABASE_SECRET_KEY }}
          NEXT_PUBLIC_MSW_ENABLED: "true"

      - name: Upload Playwright report
        uses: actions/upload-artifact@v4
        if: always()
        with:
          name: playwright-report
          path: playwright-report/
          retention-days: 7
```

## Notas de ajuste de selectores

Los tests usan selectores por rol (`getByRole`) y texto (`getByText`). Si la UI cambia los textos de los botones, ajustar los patrones regex en los tests. El orden de ajuste:

1. Correr `npx playwright test --headed` para ver el browser en vivo
2. Usar `npx playwright codegen http://localhost:3000` para capturar selectores exactos
3. Actualizar los selectores en los spec files
